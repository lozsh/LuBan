# D1-9 契约：CI 守门 + 覆盖率门槛 + .lubanagent-upstream 守卫 + Docker 交付

> 来源：`docs/design-docs/LubanAgent-development-plan.md` §D1-9、§5；`AGENTS.md` §3.2/§4.4；人工介入清单 H1/H4/H6。
> 性质：收口单元——骨架已落（untracked），本契约用于 strict-validation 校验「骨架 vs spec 契约」。

## 接口契约

| 产物 | 路径 | 职责 |
| --- | --- | --- |
| CI workflow | `.github/workflows/ci.yml` | 4 job：backend / mysql / frontend / upstream-guard |
| 依赖方向守卫 | `importlinter.toml` | 领地隔离 + 子包分层，CI 强制 |
| 覆盖率分项门槛 | `scripts/check_coverage.py` | 核心子包≥85% + 整体≥70% |
| 上游清单守卫 | `scripts/check_upstream_guard.py` | 四节格式自检 + diff 不触碰 user-owned |
| 上游清单 | `.lubanagent-upstream` | framework/shared/scaffold-seed/user-owned 四节 |
| Docker 交付 | `docker/Dockerfile` + `docker-compose.yml` | 全栈演示：app+MySQL+Langfuse+mock-biz |

## CI job 行为契约（对齐开发计划 §D1-9 + §5）

- **backend**：`ruff check` → `lint-imports --config importlinter.toml` → `alembic upgrade head && downgrade base && upgrade head`（SQLite 冒烟）→ `pytest --cov --cov-fail-under=70` + `check_coverage.py`（核心≥85%）→ `luban --help/migrate/init/eval` CLI 冒烟。
- **mysql**：`alembic upgrade head && downgrade base && upgrade head` 在 MySQL 8 实跑（D1-1 验收）。
- **frontend**：`npm ci` → `codegen:check`（OpenAPI 契约一致）→ `typecheck && lint && test && build`。
- **upstream-guard**：`check_upstream_guard.py --base <pr-base>`，上游提交不触碰 user-owned。

## 边界硬约束（代码强制，非注释声明）

1. 领地三重隔离：`lubanagent → app` 禁止、`lubanagent → lubanagent_channels` 禁止、`lubanagent/app → demos` 禁止——由 import-linter CI 强制。
2. 渠道层单向依赖核心，反向禁止。
3. core/extension/config 是最底层，不依赖兄弟包与重依赖（sqlalchemy/fastapi/langchain 等）。
4. 上游提交 diff 不触碰 user-owned glob（scaffold-seed 种子除外）。

## 验收标准（开发计划 §D1-9 原文）

1. CI 在零外部密钥环境下全绿（FakeLLM + SQLite + noop 观测 + mock 渠道兜底）。
2. 故意写一条 `lubanagent → app` 的 import，CI 立即红。
3. 覆盖率门槛生效（核心≥85%、整体≥70%）。

## 附加发布物（H6 + D0-3 验收）

- `.env.example`：D0-3 验收"齐全 + 零配置可起（SQLite + noop 兜底）"+ H1（LLM key 占位）/H4（Langfuse key 占位）。

无。骨架与发布物均已有代码事实，strict-validation 取证校验。
