# 质量文档导航 — LubanAgent

## 质量文档导航

| 文档 | 定位 |
|---|---|
| `risk-register.md` | 长期质量风险登记：已知脆弱点、未解决的技术债、需要长期关注的隐患 |
| `playbooks/index.md` | 可复用排障 / 验证手册：常见故障的定位与处理步骤 |
| `postmortems/index.md` | 长期复盘资料：重大问题的复盘记录与经验沉淀 |

## 更新原则

- 只登记**长期有效**的风险与手册，不记录一次性任务的临时排查过程。
- 每条风险/手册/复盘须有明确的事实来源（代码位置、故障时间、影响范围）。
- 无内容时保留 `[TODO: ...]` 并注明原因，不写空泛占位段落。
