# 退款标准操作流程（SOP）

## 何时使用
当用户请求退款时，按本 SOP 执行，确保流程合规。

## 步骤

1. **校验资格**：用 query_order 查订单，确认 `refundable=true`。
   - 已发货但标记可退 → 继续
   - 已取消 / 不可退 → 告知用户原因，终止
2. **计算金额**：退款金额不超过订单金额。用户未指定时默认全额退。
3. **大额审批**：金额 > 500 元触发人工审批，告知用户稍候。
4. **执行退款**：用 refund_apply 提交，记录退款单号。
5. **通知用户**：告知退款单号与预计到账时间（示例不模拟到账）。

## 边界
- 不承诺知识库未覆盖的退款时效。
- 不可退订单不强行退款，如实说明原因。
- 金额争议转人工（超出本 SOP 范围）。
