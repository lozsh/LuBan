# 开发者工作台

> 本页讲 Web 控制台的 9 个管理页面与 1 个用户端聊天入口、鉴权闭环、Agent 调试台、虚拟形象，以及调试相关的几个会话约定。

> 新手路径：第一次把工作台跑起来见 [教程第 1 课](../../tutorial/01-setup-and-first-run.md)。

Web 控制台：Agent 定义编辑与调试（调试台为「对话 + Prompt 试跑」双 Tab 工作台）、模型对比试跑、Prompt 库管理、Tool/MCP 在线测试、Skill 管理（上传/版本/分配）、知识库管理（上传/切块/重切/检索测试，见[知识与记忆](./knowledge-memory.md)）、流程图（确定性流程的只读拓扑视图）、Trace 可视化、评测报告查看。9 个管理页面 + 1 个用户端聊天入口，一个入口覆盖"定义—调试—观测—评测"的日常闭环。

**鉴权闭环**：后端开启 `AUTH_ENABLED=true` 后，顶栏提供 API Key 管理入口（状态徽章 + 对话框）：Key 仅保存在当前页面内存，不写 localStorage、不进 URL、不进构建产物，刷新页面需重新提供；REST、SSE 流、上传/头像等全部请求共用同一身份来源（`Authorization: Bearer <key>`）；收到 401 不会自动重试，顶栏徽章转红并弹出恢复对话框，换 Key 后数据自动重新拉取。走可信网关部署（网关统一注入身份）时无需填 Key。

**用户端聊天入口（/chat）**：侧栏「用户端聊天」进入无侧边栏的全屏聊天页，面向最终用户——顶部下拉选择 Agent（默认内置客服），左侧陪伴栏大号展示所选 Agent 的虚拟形象（无形象回退图标，3D 模型可拖拽旋转查看，模型内嵌说话动效时流式回复中自动播放嘴巴开合、回复结束静止；窄屏自动收起），多轮对话流式输出，工具调用只显示一行状态（正在执行/完成/失败），回复完成后按 markdown 渲染；「新会话」按钮换会话，切换 Agent 自动重开。涉及人工确认的操作（如大额退款）会在气泡内出现「批准 / 拒绝」按钮，页面内即可完成审批，对话继续（决定以当前页面身份提交并记录 `decided_by` 留痕，页面不做逐人身份核验）。**边界**：这是示例级入口——不做用户注册/登录/多租户/会话列表持久化；请求与工作台一样自动携带内存态 API Key（`AUTH_ENABLED=false` 时无需提供）；生产环境的用户端请由业务系统自建，走 REST/SSE 调用 LubanAgent（接入写法见[改造指南](../customization/overview.md)）。

**流程图页面**：查看已注册确定性流程图（如退款流水线）的节点与分支拓扑——节点按类型着色（step / agent / 人工），条件分支虚线双出边标注，入口与汇点带 START / END 标记。只读视图，实时读图定义不触发编译；**编辑图走代码**（`app/graphs/`，改流程 = 改代码发版，保持流程的可测试与可审计），本页不做可视化设计器。图怎么写见[图编排](./graphs.md)。

**Prompt 库页面**：以 Prompt 为维度管理系统提示词——列表、新建、编辑发版（新版本不可覆盖旧版本）、版本历史、分配给 Agent（反查哪些 Agent 在引用）。分配即让目标 Agent 吃该 Prompt 的当前版：系统为每个被分配的 Agent 产生一个新版本，把 Prompt 全文解析进快照（语义见 [Prompt 库](./prompt-library.md)）。Agent 编辑器的指令区也是双轨：引用态显示 Prompt 只读预览与版本徽章，可一键"转为内嵌"；内嵌态可以选择挂到某个 Prompt 引用。

**Agent 调试台**：进入某个 Agent 的调试台，是一个「对话 + Prompt 试跑」双 Tab 工作台。「对话」Tab 是围绕该 Agent 的多轮对话调试；「Prompt 试跑」Tab 并排试跑同一个 Agent 的两份 Prompt——左侧是库内定义的基线，右侧是你的修改。改 variables 即时生效；改 instructions 只是临时覆盖（本次试跑生效，不入库、不改 Agent 定义）。试跑内容可"从 Prompt 库载入"后继续改。两个 Tab 切换不丢状态，后台的流式输出也不会断流；对话与试跑各自的会话相互独立。

**虚拟形象（Agent 编辑器「身份」区）**：每个 Agent 可以上传一个展示形象——SVG / PNG 图片，或 GLB / GLTF 3D 模型（≤ 20MB）。上传立即生效并自动生成一个新版本（与表单草稿无关，改其他字段未保存也不受影响）；用户端聊天页（/chat）左侧陪伴栏会大号展示当前 Agent 的形象，3D 模型可直接拖拽旋转查看。API：`PUT /v1/agents/{key}/avatar`（multipart 上传）、`GET /v1/agents/{key}/avatar`（取形象文件）、`DELETE`（移除）。形象是纯展示字段，不进模型运行逻辑；文件落盘在 `data/avatars/`（env `AVATAR_FILES_ROOT`）。

调试相关的几个会话约定：
- **对话调试（调试台「对话」Tab）**：打开页面自动开一个新会话（生成新会话 ID），多轮对话共用；刷新页面即换新会话。Agent 若开了会话记忆，会按这个会话 ID 读写后端记忆，与页面显示的对话历史叠加生效。
- **Prompt 试跑（调试台「Prompt 试跑」Tab，并排试跑）**：每次点"并排试跑"都生成新会话 ID，原 Prompt / 修改后 Prompt 两条 Run 共用同一会话 ID——在 Trace 列表里成对可查，也避免上一轮的会话记忆污染本轮对比。试跑支持"从 Prompt 库载入"：选中一个 Prompt，把它的内容填进当前编辑态试跑（只影响本次调试，不改库里的 Prompt，也不改 Agent 定义）。
- **Trace 列表与详情**：显示每次 Run 的会话 ID 与用户标签（未传则显示 —），排查"这个用户/这通会话发生了什么"不用查库。Trace 记录的内容见[运行观测](./observability.md)。
