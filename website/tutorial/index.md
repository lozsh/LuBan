# 开发指南

这里介绍如何在 LubanAgent 中加入自己的业务：创建 Agent、接入模型、编写工具、配置知识库、验证效果，以及部署服务。

尚未确定是否采用这个项目，请先看[项目介绍](../manual/introduction.md)。只想验证服务能运行，直接看[快速开始](../manual/getting-started.md)。本指南按开发任务组织，你不需要读完所有内容才能开始使用。

## 示例与实际业务

操作示例使用图书馆借阅助手 `my-lib-assistant`，演示查询工具、高风险审批、知识检索和多 Agent 分工；仓库还自带智能客服示例。它们用于说明扩展方式，不限制你开发的业务类型。

如果按照图书馆示例操作，建议依次完成本地运行、创建 Agent、接真实模型，再加入工具与知识库。其他页面可以按任务查阅。参考配置与代码在 `reference/` 中，实际业务的接口、权限、规则和评测数据需要由你实现。

## 运行与验证

- 开发环境可以用 SQLite 和 FakeLLM 跑通链路，不需要外部模型密钥。FakeLLM 返回固定内容，不用于判断模型效果。
- 真模型的工具调用、费用和响应效果受供应商与模型版本影响，不承诺固定预算就能完成所有操作。
- 每次改动后，检查对应页面的验证项。对不上先检查环境、配置和接口响应，再查看常见问题或提交 Issue。
- 部署前落实[生产清单](../manual/deploy.md)，不要把示例配置直接作为生产配置。
